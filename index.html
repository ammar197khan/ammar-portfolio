About me

A decade of software engineering, now focused on practical AI.

I'm a software developer with 10 years of experience across web application development, backend engineering, mobile development and API integrations. I've built the kind of systems businesses run on every day: customer portals, admin panels, payment flows and the APIs that connect them.

Today my focus is AI engineering. I design and build intelligent applications, AI agents and automated workflows using large language models, retrieval-augmented generation and tools like the OpenAI API, LangChain and n8n.

That engineering background matters. AI features are only useful when they sit on top of clean data, reliable integrations and software that's easy to maintain, and that's where I spend most of my effort.

How I work

  1. Start with the business problem

    Map the current process, find where time is lost and agree what a good result looks like before choosing any tools.

  2. Use AI where it actually helps

    Pick the simplest reliable approach, whether that's a prompt, a RAG pipeline, an agent or plain automation.

  3. Keep humans in control

    Add review steps, logging and clear fallbacks so the system is safe to trust with real work.

  4. Ship, measure, improve

    Deliver in small working increments, measure the impact and hand over documented, maintainable code.
